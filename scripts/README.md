# Memory OS — Scripts

Standalone Python scripts that maintain the Qdrant vector database and wiki pipeline.

## Qdrant Maintenance

| Script | What it does | Run |
|--------|-------------|-----|
| `decay_scanner.py` | Archives low-importance, aged AI content based on half-life decay | Weekly cron |
| `backfill_decay_metadata.py` | Populates missing `importance_score`, `last_accessed_at`, `confidence_score` in Qdrant points | Run once before enabling decay scanner |
| `semantic_dedup.py` | Merges near-duplicate points (cosine >0.92) | Monthly cron |

## Context Injection

| Script | What it does | Used by |
|--------|-------------|---------|
| `context_enhancer.py` | Embedding pipeline: query → embed → search Qdrant (4-level fallback). Also provides pure-Python BM25 sparse embedding (`bm25_tf.py` — no model, no network). | Icarus `pre_llm_call` hook |

## Wiki Pipeline

| Script | What it does | Run |
|--------|-------------|-----|
| `wiki_continuous_ingest.py` | SHA-256 diff detection: finds new/modified wiki files, enqueues ARQ jobs in Redis | Hourly cron |
| `bulk_wiki_ingest.py` | One-shot bulk ingestion of all wiki files into Qdrant | After initial setup or collection rebuild |

## Quality Control

| Script | What it does | Run |
|--------|-------------|-----|
| `pre_validator.py` | Pre-flight validation of wiki documents: YAML frontmatter, required fields, link targets | Before ingestion |
| `reflection_trigger.py` | Idle detection for ARQ worker — enqueues micro-reflection when queue is empty and within hourly budget | Every 5min cron |

## Monitoring

| Script | What it does | Run |
|--------|-------------|-----|
| `dlq_manager.py` | Dead letter queue monitoring and reporting | Every 2h cron |

## Memory Evolution (facts store)

The `facts` table lives in SQLite (`memory_store.db`) rather than Qdrant, so its
maintenance job ships with the `icarus` plugin instead of this directory:

| Job | What it does | Run |
|-----|-------------|-----|
| `icarus/evolution.py --decay 30` | Decays `trust_score` of facts unused for ≥30 days (floor 0.05) — the "forget what never helped" half of the self-evolution loop | Daily cron (installed by `setup.sh`) |

## Environment variables

All scripts read configuration from environment variables. See `.env.example` in the project root for the full reference.

Dense embeddings are **remote-only** (OpenAI-compatible `POST {EMBEDDING_API_BASE}/embeddings`);
the sparse BM25 vector is generated by the pure-Python `bm25_tf.py` (no local model).

Key variables:
- `EMBEDDING_API_BASE` — dense embedding endpoint (default: `https://openrouter.ai/api/v1`)
- `EMBEDDING_API_KEY` — dense embedding key (required; falls back to `OPENROUTER_API_KEY` for OpenRouter bases)
- `EMBEDDING_MODEL` — dense embedding model (default: `qwen/qwen3-embedding-8b`)
- `EMBEDDING_DIMS` — vector dimensions (default: 4096)
- `WIKI_ROOT` — host wiki root (default: `~/vault/wiki`); `WIKI_PATH` is also honoured
- `QDRANT_URL` — Qdrant endpoint (default: `http://localhost:6333`)
- `QDRANT_COLLECTION` — Qdrant collection (default: `knowledge_base`)
- `REDIS_PASSWORD` — Redis auth (required for wiki ingest)
- `MAA_ENV_PATH` — path of the `.env` loaded by the cron scripts
- `HERMES_HOME` — Hermes state/log directory (default: `~/.hermes`)
